# Relationship Preference Reflection

Two static pages live under `/mbti-love/`:

- `index.html`: 12 choices produce a four-letter preference snapshot. Each answer adds one point to its shown letter; ties use the first answer on that axis. This is not an official MBTI assessment or compatibility score.
- `deck.html`: 12 optional conversation cards with local-only favorites.

Both pages suspend ad serving during the invalid-traffic restriction. Analytics records only exact-once funnel stages and never answers, letters, card IDs, modes, saved counts, locale, source, URLs or timing.
